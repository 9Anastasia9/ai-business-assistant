# 🤖 AI Business Assistant

An AI-powered business assistant built with Python and Streamlit to help businesses manage leads, prioritize potential customers, and automate everyday workflows.

## 🚀 Project Overview

AI Business Assistant is a practical business automation project designed to combine lead management with artificial intelligence.

The application provides a simple dashboard where users can:

- Add and manage customer leads
- Classify leads as Hot, Warm, or Cold
- Track lead information and notes
- Monitor the sales pipeline
- Prepare AI-generated customer responses
- Automate repetitive business workflows

## ✨ Current Features

- Interactive Streamlit dashboard
- Lead creation form
- Hot / Warm / Cold lead classification
- Lead pipeline visualization
- Customer notes
- Lead creation timestamps
- Session-based lead management
- Responsive web interface

## 🧠 Planned AI Features
